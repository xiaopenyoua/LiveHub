## 按钮改 Liquid Glass（tvOS 26 方向）

用户反馈两条：按钮不该是纯色、按钮切换要有动画。调研后按 Apple 官方口径重做材质与动效。

### 关键调研结论
- tvOS 26 控件材质是 **Liquid Glass**：半透明、吸收并模糊背后内容、带镜面高光。
- Apple 对 `CustomHoverEffect.highlight` 的描述：tvOS 上是 *projection effect accompanied with a specular highlight*，并随运动调整高光偏移。
- tvOS **内置 focus hover 时长 ~200ms**（透视抬升 + 镜面光泽）。这是时间参数的权威来源。
- 自定义动画要挂在 focusable 的**子元素**上，挂元素本身会与内置 hover 打架产生抖动（现有 `.card.is-focused .card__lift` 写法正好是对的）。

### 材质实现（四层，全部 inset）
底色半透明白 + `backdrop-filter:blur(24px) saturate(180%)`；顶沿 `inset 0 2px 0 rgba(255,255,255,.98)`；底部柔暗 `inset 0 -16px 24px -10px rgba(0,0,0,.24)`；底沿窄暗 `inset 0 -3px 5px -3px rgba(0,0,0,.22)`。
- 白主按钮实测顶部行亮度 246 / 底部 229，差 17 级。
- **不用 linear-gradient**：渐变不可过渡，焦点切换会硬切；`box-shadow` 能插值，高光才跟得上。
- **不做外投影**：真黑底上无效（这条沿用上一轮结论）。
- 小控件（分段选中块、开关轨道）用 `--spec-chip` 短版，避免 16px 柔暗压脏。

### 动效
`--dur:200ms`、`--dur-press:120ms`、`--ease:cubic-bezier(.32,.72,0,1)`。
`--t-surface` 必须含 `box-shadow`，否则"块变大了、光没跟上"。
顶栏改**焦点胶囊**：`.tabs__pill` 绝对定位，用 `offsetLeft/offsetWidth` 定位（**不能用 getBoundingClientRect**，读到的是过渡中间值会跑偏）；换屏传 instant 避免跨屏滑动。260ms。
顺带把 tab 从 `padding:10px 2px`（约 50px 高）扩到 `11px 24px`，解决上一轮遗留的"最弱焦点目标"。

### 闸门边界（重要，以后别再踩）
- lint 的 `shadow` 在 app 模式降级 WARN；`glass` 本来 WARN；`gradient` / `button-fx` **不降级**。
- **lint 的 appMode 读 `.taste-skill/direction.json`，而本项目该文件在 `.taste-skill/app/` 下**，所以必须显式带 `--app`，否则 shadow 按页面规则判 FAIL。
- inspect 的 `judgeApp` 里**没有** gradient / button-fx，但 `judge()` 路径会跑，所以仍会报 `button-fx`（`m.buttons.withShadow` 连 inset 也算）。
- `heavy-shadow` 只看**非 inset** 的外阴影，且 darkGround 下 `alpha>=0.45` 才算重；`inset` 直接跳过。
- 结论：按钮玻璃必须 `--allow button-fx`，理由已写 README（18→20 处全是 inset，逐条核对过）。

### 结果
lint 0 FAIL / 31 WARN；inspect 0 FAIL / 1 WARN；selftest 12 步全通，焦点困住 6/40 不变。八张截图已重出。
