# LiveHub 功能清单

> 版本：应用版本 `0.1.0`（`android/app/build.gradle.kts`），设计定稿 `design/v1.0.0/`
> 这份清单回答「这个应用到底有哪些功能、每个功能落没落地」。测试用例编号见 `android/docs/测试方案.md`。
> 状态只有四种：**已实现** / **部分实现**（有明确缺口） / **未实现**（v1 明确不做） / **灰置**（设置里可见但不可聚焦）。
> 代码定位只写「文件 + 条件/符号」，不写行号——行号会漂，条件不会。

---

## 0. 一句话

聚合哔哩哔哩、斗鱼、虎牙、抖音四家直播的 Android TV 客户端：**四个平台，一台电视，像换台一样换主播**。
产品三根柱子：换台优先、房间号就是房间号、状态诚实（不假装在播、不假装有原画）。

## 9. 错误归责（`core/model/SiteError.kt`）

13 个错误码：`NET_OFFLINE / NET_TIMEOUT / HTTP_4XX / HTTP_5XX / RATE_LIMITED / SIGN_INVALID / PARSE_BROKEN / ROOM_NOT_FOUND / ID_UNRESOLVED / STREAM_OFFLINE / GEO_BLOCKED / DECODE_UNSUPPORTED / DANMAKU_PROTOCOL`。

- UI 只按 `kind` 查文案（`ui/strings/SiteErrorText.kt`），`detail` 不上屏。
- `retryable` 决定给「重试」还是「换线路 / 回首页」。
- 2026-10-30 修复：`Net` 先判状态码再信任 body 读取（403 不再被说成「网络不稳」）；哔哩 `60004` 归 `ROOM_NOT_FOUND`。

## 11. 明确未实现（v1 不做）

| 项 | 原因 |
|---|---|
| 抖音推荐 / 分区 / 搜索 / 弹幕 | 需要 `a_bogus` / `X-Bogus` 签名（WebView 或 QuickJS 跑平台脚本）；首版不引 JS 引擎 |
| 账号扫码登录 | 账号是最大风险面；收益只是清晰度上限，且不登录也能拿到原画房间 |
| 关注列表云同步 | 本地 SharedPreferences，换设备不同步 |
| 多用户档案 | 一家人共用一台电视会混关注列表；需产品决策 |
| 字号缩放 / Dynamic Type | 原型硬编码 px，未接系统字号 |
| 手机 / 平板 UI | 只保留调试入口 |
| IPTV / m3u | 超出四平台聚合范围 |
| 竖屏 / 多分辨率适配 | 本轮只测 1920×1080 |
